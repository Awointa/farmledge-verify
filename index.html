Check a warehouse proof against the ledger

A Farmledge proof bundle is Farmledge's claim about a deposit. It can reach you any way at all: from the farmer, by text message, or downloaded from a Farmledge server. That does not weaken this check.

This page does not take Farmledge's word for anything. It checks the claim against the Stellar ledger, in your browser, and reads nothing else: no Farmledge server computes or reports the result. We are not asking you to trust us. We are proving we cannot have rewritten the books.

Verify this yourself, without this page

This page is a convenience. Anyone with Python 3 and nothing else can run the same check:

  1. Download verify_proof.py (about 200 lines, standard library only; read it).
  2. Run python3 verify_proof.py bundle.json --rpc https://soroban-testnet.stellar.org
  3. Read the last line: RESULT OK or RESULT DAY_ROOT_EXPIRED are the only two verified results. Every other result is not.

Step-by-step instructions, and what each result means, are in the README. The script is pinned by SHA-256 to Farmledge's protocol repository.

Static files, no server, no tracking. The page and its tests are open source: github.com/Awointa/farmledge-verify, Apache 2.0.
